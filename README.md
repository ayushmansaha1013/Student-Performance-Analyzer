# Student-Performance-Analyzer



A beginner-to-intermediate Python project for managing student information and analyzing academic performance.

The project is being built incrementally to practice **Python fundamentals, Object-Oriented Programming, modular design, file handling, validation, and Git/GitHub workflows**.

## Current Status

**Phase 1 — Student Class: Complete**

Currently implemented:

* Student data storage
* Total marks calculation
* Average marks calculation
* Grade calculation

The remaining features will be added incrementally.

## Current Student Class

The `Student` class represents an individual student and currently stores:

* Name
* Roll number
* Marks
* Subjects

It provides methods to:

* Calculate total marks
* Calculate average marks
* Calculate grade
